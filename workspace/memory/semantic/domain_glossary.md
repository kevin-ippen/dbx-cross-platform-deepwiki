# Domain Glossary

> Org-wide terms that are non-obvious or used in non-standard ways.
> Agents should check here before assuming what a term means.

## Databricks Platform

| Term | Definition |
|------|------------|
| **DAB** | Databricks Asset Bundle — YAML-defined deployment unit for notebooks, jobs, apps |
| **FMAPI** | Foundation Model API — Databricks-hosted LLM endpoints (Claude, Llama, Mistral, etc.) |
| **UC** | Unity Catalog — Databricks' unified governance layer for data and AI assets |
| **VS** | Vector Search — managed vector index service within Databricks |
| **DLT** | Delta Live Tables — declarative streaming/batch pipeline framework |
| **Serverless** | Databricks compute that auto-scales without managing clusters; `client: "1"` in notebooks |
| **Medallion** | Bronze → Silver → Gold layered data architecture pattern |
| **Genie Code** | Databricks' AI coding assistant with MCP tool support |
| **MCP** | Model Context Protocol — standard for exposing tools to agents |
