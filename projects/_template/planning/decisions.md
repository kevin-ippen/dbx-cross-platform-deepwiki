# Architectural Decisions

> Agent-proposed, human-approved. Append-only — never delete a decision.
> If a decision is reversed, add a new entry noting the reversal and why.

## Format

```
### D{N}: {Title}
- **Date:** YYYY-MM-DD
- **Status:** proposed | approved | reversed
- **Context:** Why did this decision need to be made?
- **Decision:** What was decided?
- **Rationale:** Why this option over the alternatives?
- **Consequences:** What does this make easier? Harder?
- **Reversing Entry:** (if reversed) D{M} on YYYY-MM-DD
```
